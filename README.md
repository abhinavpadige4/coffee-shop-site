# Cozy Corner Coffee Shop

A responsive, accessible, SEO-optimized single-page coffee shop website built with plain HTML5, CSS3, and Vanilla JavaScript.

## Features

- **Responsive Design**: Works on mobile, tablet, and desktop devices
- **Accessibility**: WCAG 2.1 AA compliant with proper semantic HTML, ARIA labels, and keyboard navigation
- **SEO Optimized**: Includes meta tags, Open Graph, JSON-LD structured data for LocalBusiness
- **Menu Section**: Displays espresso, latte, and pastries with prices
- **Hours Section**: Shows opening hours for weekdays and weekends
- **Location Section**: Includes address and embedded Google Mapbox map
- **Contact Form**: With client-side validation and success feedback
- **Interactive Elements**: Mobile navigation toggle, header scroll effect, smooth scrolling, back-to-top button
